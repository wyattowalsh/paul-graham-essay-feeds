# Roadmap

## 0.1.0: multi-format foundation

- Canonical typed item and state model.
- RSS 2.0, Atom 1.0, JSON Feed 1.1 renderers.
- OPML 2.0 subscription catalog.
- Safe fetch, extraction, reconciliation, atomic build, and validation pipeline.
- CLI, tests, CI, scheduled updates, and Vercel static deployment.

## 0.2.0: operational maturity

- Better change reports and update provenance.
- Optional release assets and content negotiation examples.
- Post-deploy validator checks.
- Reader compatibility matrix.

## 1.0.0: stable contract

- Frozen canonical state schema and CLI contract.
- Documented migration policy.
- Proven unattended update history.

## Explicitly out of scope

- Full-text republication.
- Invented or heuristically scraped publication dates.
- RSS 0.9x, RSS 1.0/RDF, or other obsolete dialects.
- Non-essay Paul Graham content unless the repository is intentionally renamed
  and rescoped.
