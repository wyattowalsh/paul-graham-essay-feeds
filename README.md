# paul-graham-essay-feeds

Unofficial multi-format metadata feeds for Paul Graham’s essays.

**Package root:** [`paul-graham-essay-feeds/`](./paul-graham-essay-feeds/)

```bash
cd paul-graham-essay-feeds
uv sync --all-groups
uv run pg-essay-feeds --help
```

Hosting: **Vercel** (see package `vercel.json` and `docs/deployment.md`).  
CI workflows: [`.github/workflows/`](./.github/workflows/) (run with
`working-directory: paul-graham-essay-feeds`).
